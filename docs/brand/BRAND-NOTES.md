# 品牌统一速查 · 觅图采集器 v1.7.4

> 试用这份文档时，先把扩展刷新到新版（见文末「怎么用上新版」）。

## 一句话概括

插件已从「素材采集器 · LAN Collector」并入 **觅图 Mito** 体系：
**同一个 logo、同一个名称标识、同一套深色外观**，与觅图主站放在一起是一套。

## 改了什么

### 1. Logo —— 换成觅图的「取景框」标记

| | 之前 | 现在 |
|---|---|---|
| 图形 | 照片卡 + 下落箭头 | 觅图取景框（四角标 + 对焦环 + 中心点） |
| 配色 | 靛蓝 `#6366F1` → 天青 `#0EA5E9` 渐变 | 觅图 brand ink `#14171C` 底 + 白色标记 |
| 来源 | 插件自绘 | 与觅图主站页头**同一个 SVG** |

四个尺寸（16/32/48/128）全部重做。小尺寸按常规做法分级笔画：
16px 加粗到 14 并省略对焦环 —— 否则 9/120 的线宽在 16px 下只有 1.2px，会糊成一团。

**看得到的四处**：浏览器工具栏图标、扩展管理页卡片、右键菜单项前的图标（浏览器不支持单独配图，一律取扩展图标）、弹窗页头。

### 2. 名称标识 —— 统一为觅图家族

| 位置 | 之前 | 现在 |
|---|---|---|
| 扩展名 | 素材采集器 · LAN Collector | **觅图采集器 · Mito Collector** |
| 右键菜单项 | 将图片保存至 LAN Collector | **将图片保存至觅图** |
| 工具栏悬浮提示 | 素材采集器 1.7.4 · … | 觅图采集器 1.7.4 · … |
| 页头标识 | 素材采集器 | 觅图采集器 **Mito Collector**（中英双标） |

> 右键菜单文案改了。旧版习惯是找「将图片保存至 LAN Collector」，现在要找「**将图片保存至觅图**」。

**为什么菜单叫「将图片保存至觅图」而不是「保存至素材库」**：觅图主系统对目标目录的正式称法是
**「图库」**（顶栏图库标签、管理页「网络共享」），"素材库 clips"只是那个文件夹的名字。
菜单里写「觅图」既短又指向正确 —— 图存进那个目录，觅图就能索引到它，两边术语也接得上。

顺带一个背景：觅图主系统的定位是「**只做索引与检索，从不做整理**」，
README 原文写着"剪藏、归类、归档这些活留给你在文件管理器里做"。
**采集器正好补的是觅图刻意留空的那一环** —— 觅图负责找，采集器负责存。
这个分工也是两套系统能松耦合的基础。

## 试用时留意

- **弹窗面板** —— 打开扩展图标，最直观的入口。
- **右键菜单** —— 在任意图片上点右键，找「将图片保存至觅图」。
- **设置页** —— 深色表单、卡片、标签、选中态都可看。
- **素材工作台** —— 图墙与右侧面板的深色适配。
- **使用说明页** —— 长文页的代码块、表格、提示框。

## 怎么用上新版

扩展是「加载已解压」方式，**不要移除重装** —— 移除会连带删掉存储（NAS 账号密码、常用位置、各项开关、累计统计全没）。

1. 打开扩展管理页：Edge `edge://extensions` / Chrome `chrome://extensions` / 夸克 `quark://extensions`
2. 找到本扩展，点卡片上的 **↻ 刷新**
3. **已经打开的标签页按一下 F5** —— 那些页面里挂的还是旧脚本，它的 `chrome.runtime` 已断开，表现是「点保存报错」。这一条项目里踩过好几次了。

图标和名称要等刷新后才更新，右键菜单则需要后台重新跑一遍 —— 打开一次扩展面板就会自动重建。

## 有问题随时说

试用中如果发现哪里看着别扭 —— 比如某个字号偏小、某个按钮颜色不对、深色下某段文字对比度不够 ——
直接指出来就行，这类视觉问题改起来很快。

**需要我改的常见几类：**
- 某处颜色/字号/间距不对
- 配色想跟工坊那套暖调对齐
- 名称还想再调（比如菜单项措辞、是否要「Mito」出现在别处）
- 觅图主站改了品牌色，插件跟着同步
